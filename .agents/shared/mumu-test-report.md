## 一、adb 恢复过程（根因与解决方案）

### 问题

`adb` 无法启动：

```
* daemon not running; starting now at tcp:5037
could not read ok from ADB Server
* failed to start daemon
```

### 排查过程

| 步骤 | 发现 |
| --- | --- |
| 1. 检查 5037 占用 | `xray` 进程占用 `172.18.0.1:5037`（出站连接，非监听） |
| 2. 检查排除端口 | `netsh` 显示排除 5357 与 50000-50059，**不含 5037** |
| 3. 测试绑定 5037 | `EACCES: permission denied` |
| 4. 测试绑定 5038/5040 | **同样 EACCES** |
| 5. 二分测试 | **6300 以下全部拒绝，6300 以上可用** |
| 6. 绑定 18888/18889 | ✅ 成功 |

### 根因

**DSH 沙箱对 loopback 端口有下限限制（约 6300）**，adb 默认的 5037 落在禁用区。

**不是端口冲突**，也**不是 xray 的问题**。

### 解决方案

```powershell
$env:ANDROID_ADB_SERVER_PORT = "15037"
adb start-server
# * daemon started successfully
# TCP 127.0.0.1:15037 LISTENING
```

### 连带发现

模拟器默认用 5554/5555，但这两个端口**被 xray/sing-box 代理占用**，于是 emulator 自动跳到 **5556/5557**。

## 四、分类页布局实测（关键数据）

### 实测坐标（1280×720 像素）

| 区域 | y 范围 | 高度 |
| --- | --- | --- |
| 标题「分类」 | 24–64 | 40px |
| 一级类型（3 个） | 88–136 | 48px |
| 题材第 1 行（12 个） | 170–218 | 48px |
| 题材第 2 行（12 个） | 250–322 | 72px |
| **题材第 3 行（1 个「剧情」）** | **330–378** | **48px** |
| 加载更多按钮 | 624 | — |

### 与之前推演的对比（修正）

| 项 | 之前推演 | **MuMu 实测** |
| --- | --- | --- |
| 题材标签行数 | 4 行 | **3 行** |
| 每行数量 | 8 个 | **12 个** |
| 标签宽度 | 85dp | **84px** |
| 筛选区总高 | 232px | **378px** |

**实测比推演更严重**：筛选区占 **378px（52.5% 屏高）**。

### 核心问题

```
筛选区 378px + 网格需 345px = 723px > 720px 屏幕高度
```

**网格仅剩 342px，不足一行卡片高度（345px）** —— 卡片被裁切。

### 额外问题

**题材第 3 行只有「剧情」1 个孤立标签**，浪费整行 48px。

## 六、操作经验（供后续任务参考）

### 关键操作序列

```powershell
$env:ANDROID_ADB_SERVER_PORT = "15037"
$adb = "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe"
$d = "127.0.0.1:16384"

# 进入分类页（已验证有效）
adb -s $d shell input keyevent 82   # MENU 唤出 chrome
Start-Sleep 3
adb -s $d shell input keyevent 19   # UP → 焦点直接落在「分类」
Start-Sleep 2
adb -s $d shell input keyevent 23   # ENTER 进入
```

### 重要发现

| 项 | 说明 |
| --- | --- |
| **UP 后焦点直接是「分类」** | 无需按 RIGHT（按了反而跳到「榜单」） |
| `input tap` 无效 | 播放页会吞掉触摸事件 |
| chrome 会自动隐藏 | 5 秒后隐藏，需及时操作 |
| dump 大小可判断页面 | 4430=播放页，15764=chrome，20887=分类页 |
