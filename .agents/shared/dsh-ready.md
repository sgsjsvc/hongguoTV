**用户需求**：

> 使用上下键切换剧时只显示这个（剧名），不要显示整个菜单，从而方便短剧的切换。
> 同一短剧再自动下一集时不要显示菜单。增加加载动画。

**范围**：用户明确「**只针对 TV 端修改**」。Web / PC / Windows **不在本轮范围**。

#### 根因（协调者核实）

| 需求 | 根因 |
| --- | --- |
| 切剧显示整个菜单 | `selectFeed():833` 调 `revealChrome()`（显示全部 chrome） |
| 自动下一集显示菜单 | `episodeEnded():794` → `loadEpisode():755/772` 调 `revealChrome()` |
| 无加载动画 | 仅有文字 `"· 加载中"` |

#### 两条关键约束（已写入 brief）

**约束一**：`revealChrome()` 有 **9 个调用点**，其中 **7 个需要完整 chrome**（返回首页、错误提示、按 MENU 等）。**不可修改该函数本身**，必须新增轻量提示层。

**约束二**：`loadEpisode()` 有 **13 个调用点**，其中仅 `episodeEnded`（自动下一集）与 `selectFeed`（切剧）需要轻量提示；用户主动操作（点下一集、选画质、重试）**不应**显示。需**在调用点控制**。

#### 重点回归项

**用户按 MENU 必须仍能唤出完整 chrome** —— 这是本次改动最可能引入的回归，已列为验收项与复核重点。
