# 项目现状

更新日期：2026-10-15。

已实现 Web / Windows / Android TV 独立内容引擎、SQLite 资料库和可选家庭共享同步。
历史统一海报网格，无来源分类；TV 无删除／清空能力。

## 本轮完成

**播放链路**

- 修复三端全部无法播放：上游对固定设备标识静默封禁（HTTP 200 + 空响应体），
  现改为每次请求生成独立设备标识，并补齐跨端随机源（TV 的 QuickJS 无 `randomBytes`）
- 新增分层诊断工具 `npm run diagnose` 与发布前播放冒烟门禁 `npm run smoke`
- 引擎结构上移除可复用设备常量，遗漏设备参数会直接抛错而非静默回落

**全屏**

- 推荐流新增全屏按钮；详情页修正全屏样式被普通布局覆盖的问题
- 真·屏幕全屏（覆盖任务栏），全屏下保留自动下一集
- Electron 用主进程 `setFullScreen`，绕过渲染进程的窗口焦点限制

**分页**

- 分类与排行榜改为自动分页，移除「加载更多」按钮
- 修复分页后的选中状态、焦点与滚动位置
- 修复榜单条目重复追加（120 → 100，与上游一致）

**服务稳定性**

- 端口被占用时自动递增（8788 → 8789 → …），不再启动失败
- `HG_PORT` 显式指定时不递增，占用即报错并给出释放指引

**界面**

- TV 分类页改左侧双列布局（类型 + 题材）
- TV 卡片改内容驱动高度，消除底部空白
