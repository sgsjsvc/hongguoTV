## 📝 详细任务分解与实施方案

### 任务 01：播放页「猜你喜欢」专区 (同类好剧 · 看了又看)
- **目标**: 充分利用播放器正下方的留白空间，为用户提供紧密贴合当前短剧题材的高质量相关剧集，实现顺畅的一键换剧体验。
- **涉及文件**:
  - `apps/web-pc/src/App.tsx`
  - `apps/web-pc/src/api.ts`
- **验收标准**:
  - [x] 进入任意短剧播放页，下方自动渲染同题材推荐列表；
  - [x] 点击卡片能够直接切换播放对应剧集，无报错；
  - [x] 针对漫剧、AI剧、真人剧均能自适应推荐。

---

### 任务 02：「🔄 换一批」智能实时换剧与微动效交互
- **目标**: 提升推荐界面的可交互性与新鲜度，解决单屏推荐有限、观众不感兴趣时无法换剧的问题。
- **涉及文件**:
  - `custom-server/index.mjs`
  - `apps/web-pc/src/api.ts`
  - `apps/web-pc/src/App.tsx`
- **验收标准**:
  - [x] 点击「换一批」按钮，卡片列表平滑刷新为新一批 16 部短剧；
  - [x] 旋转图标动效流畅且支持连续点击；
  - [x] 连续多次点击能够循环或无缝获取新剧，永不出现空白。

---

### 任务 03：全剧终「片尾推荐弹窗」（沉浸式自动连播与倒计时）
- **目标**: 短剧每集节奏极快，追完全剧最后一集时通常产生内容断点。通过片尾自动弹窗与倒计时无缝连播，打造不中断的沉浸式追剧闭环。
- **涉及文件**:
  - `apps/web-pc/src/App.tsx`
- **验收标准**:
  - [x] 播至最后一集结束时，精准触发全剧终弹窗；
  - [x] 5 秒倒计时正常走字；
  - [x] 点击“立即观看”或倒计时结束自动进入推荐剧播放；
  - [x] 正常中间集数不受任何影响（中间集数保持正常的自动连播下一集）；
  - [x] 严格限制只有在全剧彻底播放完毕后才显示，播放过程中绝不显示。

---

### 任务 04：多季短剧智能识别、季数切换栏与季终优先连播下一季
- **目标**: 解决短剧多季（例如第一季/第二季/第三部）各自割裂、无法在播放器中直接切换季数、当前季完结后不能顺畅进入下一季的核心痛点。
- **涉及文件**:
  - `shared/utils.ts` (系列剧名正则提取、季数解析排序)
  - `apps/web-pc/src/api.ts` & `custom-server/index.mjs` (系列剧检索聚合)
  - `apps/web-pc/src/App.tsx` (季数切换胶囊栏、下一季连播调度)
- **实现方案**:
  1. **季数命名特征智能解析算法**:
     - 建立短剧季数提取正则引擎，精准识别中文季数（第X季/部/卷）与英文季数（SX/Season X）；
     - 自动提取出**系列主剧名 (baseTitle)** 与 **季数序列值 (seasonNumber, seasonLabel)**；
  2. **多季聚合池检索**:
     - 进入短剧播放时，自动使用 `baseTitle` 搜索并匹配同系列剧集，去重后按 `seasonNumber` 从小到大升序排列；
  3. **UI 季数切换胶囊栏**:
     - 若同系列存在 >= 2 季，在选集头部上方渲染高亮胶囊切换组：
       - 例如：`[ 第1季 ]`  `[ 第2季 (当前) ]`  `[ 第3季 ]`；
       - 点击任意季直接平滑载入该季剧集，记忆历史播放进度；
  4. **季终优先连播下一季**:
     - 当当前季播放到全剧最后一集最后一秒时：
       - 若存在下一季（如当前是第 1 季，检测到有第 2 季），**最高优先级**将推荐目标锁定为《下一季》第 1 集！
       - 弹窗专属文案：`🏆 恭喜追完第 1 季！即将为您自动连播《第 2 季》`；
       - 若已是最终季，则回退至同类好剧推荐。
- **验收标准**:
  - [ ] 多季短剧在播放详情页自动展现季数切换栏；
  - [ ] 点击季数能平滑切换对应季短剧播放；
  - [ ] 当前季播完后，片尾推荐弹窗优先自动连播下一季第 1 集。

---

### 任务 05：全功能「观看历史」专区 (进度条、一键续播、管理删除)
- **目标**: 为用户提供专属的历史足迹，清晰呈现每一部看过的短剧、最后观看集数、时间百分比进度，随时一键续播。
- **涉及文件**:
  - `shared/types.ts`
  - `apps/web-pc/src/api.ts`
  - `apps/web-pc/src/App.tsx`
- **实现方案**:
  1. **数据模型扩展**:
     - 完善 `HistoryItem` 数据结构（剧ID、封面、标题、集ID、集数、最后观看秒数、总秒数、更新时间戳）；
  2. **双选项卡布局**:
     - 导航栏「追剧」页面升级为顶部微切换：`【❤️ 我的追剧】` 与 `【🕒 观看历史】`；
  3. **卡片视觉与操作**:
     - 显示「看到第 X 集 02:15」与底部红色进度条；
     - 卡片悬浮出现「▶ 继续观看」与「🗑️ 删除记录」；
     - 顶部右上角提供「清空全部历史」二次确认功能。
- **验收标准**:
  - [x] 播放过的短剧能实时进入观看历史列表；
  - [x] 历史卡片准确显示集数与进度条；
  - [x] 点击卡片或“继续观看”能精准恢复到上次播放秒数；
  - [x] 支持单条删除与清空全部历史。

---

### 任务 06：搜索体验全方位增强 (热搜榜、搜索历史、实时输入联想、快筛)
- **目标**: 打造媲美官方 App 的搜索中心，让用户能发现爆款热搜词、保留历史足迹、输入时实时联想。
- **涉及文件**:
  - `apps/web-pc/src/App.tsx`
  - `apps/web-pc/src/api.ts`
- **实现方案**:
  1. **热门搜索词榜单**:
     - 提取当前热播榜 Top 10 作为热搜词胶囊标签（如“太奶奶”、“白月光”、“逆袭”），一键点击直接搜索；
  2. **本地搜索历史**:
     - 本地保存最近 10 条搜索词，支持点击回填搜索与一键清除；
  3. **实时输入联想 (Autocomplete Suggestions)**:
     - 搜索框输入时进行 250ms 防抖，实时下拉展示前 6 部匹配剧名与题材，点击即看；
  4. **搜索结果题材快筛栏**:
     - 搜索结果上方提供「全部 / 真人 / 漫剧 / 逆袭 / 甜宠」分类微标签，支持在搜索结果内二次过滤。
- **验收标准**:
  - [x] 搜索页空状态展示热搜榜与搜索历史；
  - [x] 输入框输入时展示实时防抖下拉联想；
  - [x] 搜索历史支持持久化存储与清理。

---

### 任务 07：红果沉浸式刷剧推荐页 (PC滚轮/上下键切剧)
- **目标**: 打造媲美官方红果 App 的沉浸式垂直短剧流页面，让 Web 与 Windows 用户像刷短视频一样无缝连刷海量爆款短剧。
- **设计准则 (依用户要求严格精简克制)**:
  - ❌ **剔除项**: 不做手机手指轻触上下划、不做双击屏幕爱心点赞动效、不做评论选集弹窗、不做分享/快捷键提示。
  - ✅ **保留并专注的核心要素**:
    1. **沉浸式 9:16 竖屏大流容器**: 剧中自适应、背景带有毛玻璃虚化氛围光影、底部极细沉浸播放进度条；
    2. **流畅切剧控制**:
       - PC / Web 端：鼠标滚轮向上/向下滚动切剧、键盘 `↑` / `↓` 键切剧、屏幕悬浮上下切换按钮；
    3. **右侧精简操作**: 仅保留 ⭐ **一键追剧/收藏** 按钮（高亮心动状态）；
    4. **左下角短剧信息层**:
       - 🎬 **系列剧胶囊**（识别出多季时，标注 `系列剧 ... | 第X季`，点击可查看同系列剧）；
       - 🏷️ **剧名与题材标签**；
       - 📝 **剧情简介折叠与展开**；
    5. **底部核心入口**:
       - 🌟 **「▶ 观看完整剧集 · 全XX集 >」** 醒目行动条，点击后无缝跳转进入该剧完整播放页（包含选集网格、官方多画质与倍速调节）；
    6. **数据驱动**:
       - 基于 `GET /api/recommend?page=N` 无限流引擎，提前预加载下一页剧集，实现无尽随刷随看。
- **涉及文件**:
  - `apps/web-pc/src/App.tsx`
  - `apps/web-pc/src/api.ts`
- **验收标准**:
  - [x] 导航栏提供沉浸式「推荐」刷剧独立页面，支持全幅满屏无空白；
  - [x] PC 端支持鼠标滚轮与键盘上下键平滑切剧，自动连播；
  - [x] 右侧精简纵向操作栏与左下角合集胶囊；
  - [x] 顶部提供播放倍速选择 (0.75x ~ 3x) 与官方清晰度画质 (1080P ~ 360P) 调节；
  - [x] 底部提供精确时间感知与可拖动/可点击交互式进度条；
  - [x] 当前一集播完后在此页面自动无缝播放下一集，支持手动快速点播「下一集」；
  - [x] 底部「进入完整播放页」与合集胶囊支持无缝跳转；
  - *(当前仅维护 Web 浏览器与 Windows 桌面端)*
