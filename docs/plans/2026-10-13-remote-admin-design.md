# 远程共享管理平台设计

日期：2026-10-13。用户已选择完整资料管理。

在现有共享服务 8791 的首页内置浏览器界面，使用 HTML/CSS/ES modules，不引入额外部署或第三方 CDN。家庭密钥用于登录，凭据仅存在当前页面内存，刷新后重新登录。静态登录页公开，所有管理查询与操作使用既有 Bearer 认证。

页面采用深色、红色强调色，与当前产品保持一致，支持电脑与手机。提供概览（资料数量、事件游标）、设备活动（设备 ID 和最近事件时间，明确不表示在线状态）、收藏与历史海报卡、搜索记录和播放偏好设置。支持查询过滤、单条删除、清空确认和手动刷新。

管理操作复用 LibraryStore.write，在同一事务产生唯一事件，客户端经既有增量同步接收。清空／删除保留标记，不物理删除事件，避免旧离线数据恢复。请求使用唯一操作 ID 防止重试重复写入。TV 本身仍无删除能力，但接受其他端合法同步的删除。

不增加账号、媒体播放、内容获取、密钥更换或服务器部署功能；不在 URL 放密钥、不返回服务器共享密钥。会话请求失败保留页面数据并显示可重试的错误，401 清除凭据。危险操作明确说明影响全部共享设备。

验证：未登录禁止读写、操作限制／幂等、删除后旧数据不复活、管理偏好传到客户端、浏览器登录和确认流程、响应式显示、现有同步回归。远程 Docker 与 Linux 包需携带静态资源。
