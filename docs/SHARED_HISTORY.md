# 历史与家庭共享资料

本轮替代了历史统一存于 8788 并按端分类的方案。每个独立端在 SQLite 保存完整资料，配置远程后双向同步。历史页面统一按最近观看排列，每部剧一张海报续播卡，展示集数、进度和时间。

播放每秒记录，暂停、跳转、切剧、结束、退出立即记录，允许重看和快退。唯一事件 ID、设备序号、服务器校时与删除标记支持幂等重试、迟到事件隔离及删除防复活。

已完成单集续播下一集，全剧完成从最后一集开头播放。Web / 电脑保留单条删除和清空确认；TV 不提供删除或清空历史操作。

收藏、搜索及默认画质／倍速一起同步，关闭远程保留本地数据。协议、迁移和部署见 [LOCAL_REMOTE_SERVICES.md](LOCAL_REMOTE_SERVICES.md)。
