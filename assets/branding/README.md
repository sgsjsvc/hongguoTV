# 红果 TV 应用图标

由内置 ImageGen 生成，原始 PNG 为 1254×1254。v1 红底白果保留为设计版本，v2 为当前采用的白底红果版本。

最终设计提示：保持果实、叶片、播放三角的形状与构图不变，仅交换红色和白色：白色背景、珊瑚红 #F43F5E 果实及叶片、白色播放三角。无文字、边框、水印或设备模型。

Android 工程使用 v2 导出的 mdpi / hdpi / xhdpi / xxhdpi / xxxhdpi 图标（48 / 72 / 96 / 144 / 192 px），并提供白底 320×180 TV 启动器横幅。导出仅缩放及横幅留白，不改变图形设计。
